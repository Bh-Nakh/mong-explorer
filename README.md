# 몽탐색기

윈도우 탐색기 여러 개를 한 창에 **칸**으로 나누어 쓰는 앱. 각 칸의 파일 보기는 윈도우 셸의 진짜 탐색기 부품(ExplorerBrowser)이라 우클릭 메뉴·끌어놓기·이름 바꾸기·보기 방식·정렬·미리 보기 창이 탐색기와 같다.

## 실행 / 설정 / 업데이트
- 실행: `몽탐색기.exe` 하나면 된다 (윈도우 10/11 기본 .NET Framework 4 사용, 설치 필요 없음). 폴더 경로를 인자로 주면 그 폴더를 새 탭으로
- **설정은 exe 옆** `몽탐색기.settings.json`(예전 이름 `NewExplorer.settings.json` 도 읽음) — exe 폴더째 옮기면 탭·즐겨찾기·옵션도 같이 간다. 오류 기록은 `몽탐색기.error.log`
  - 처음 실행 때 exe 옆에 설정이 없으면 예전 위치(`%APPDATA%\NewExplorer\settings.json`)에서 가져옴
  - exe 를 쓰기 금지 폴더(Program Files 등)에 두면 저장되지 않음 → 안내가 뜸
- **자동 업데이트**: 앱을 켤 때(10초 뒤)·30분마다·도움말 → 업데이트 확인·메뉴 줄 오른쪽 버전 칸(`v1.11`)을 누를 때 확인. 새 버전이면 안내창이 뜨고, 사용자가 [예]를 누르면 받아서(해시 확인) 자기 exe 를 바꾸고 다시 시작 (탭은 그대로 복원)
  - 공개 배포 저장소 `Bh-Nakh/mong-downloads` 의 Release 에서 `mongexplorer-latest.json` 과 `MongExplorer.exe` 를 읽음(토큰 불필요). 공통 모듈은 `src\MongUpdate.cs`(브랜딩\앱연동 원본). 옛 이름 `NewExplorer.exe` 로 돌던 PC 는 업데이트하면서 `몽탐색기.exe` 로 갈아탐
  - 옛 버전(토큰 방식)을 쓰는 PC 가 새 방식으로 넘어오도록, 비공개 저장소의 `VERSION` 과 `release/몽탐색기.exe`(옛 이름 `release/NewExplorer.exe` 포함)도 계속 갱신한다

## 화면
- **칸 배치**: 메뉴 오른쪽 그림 버튼 또는 보기 → 칸 배치 (1칸, 1×2 좌우, 2×1 위아래, 2×2). 칸 사이 경계는 끌어서 크기 조절
- **칸 위치 바꾸기**: 탭 줄의 빈 곳을 잡고 다른 칸 탭 줄로 끌어 놓기, 또는 탭 줄 우클릭·보기 메뉴 → 칸 위치 바꾸기 (탭·기록·보기 그대로 자리만 바뀜)
- **폴더 트리**(왼쪽 위): 칸을 누를 때마다 그 칸의 폴더가 선택·펼침. 기본은 드라이브만 표시 (보기 → 폴더 트리에 드라이브만 표시 끄면 즐겨찾기·바탕 화면·라이브러리·내 PC·네트워크)
- **즐겨찾기**(왼쪽 아래): 윈도우 탐색기 빠른 실행에 고정한 폴더와 항상 같은 목록 (몽탐색기에서 추가·삭제해도 윈도우에 반영). `D:\작업\몽탐색기` → `D:\작..\몽탐색기`. 한 번 누르면 활성 칸이 이동, 가운데 클릭은 새 탭. + 버튼·Ctrl+D·폴더를 끌어다 놓기로 추가, 끌어서 순서 변경, 우클릭으로 삭제
- **탭**: 칸마다 여러 개. 고른 탭은 아래 경로 줄과 이어진 밝은 탭 + 위쪽 색 띠(활성 칸은 파랑). 이름은 즐겨찾기와 같은 줄임 표기 (시작 폴더 글자 수는 보기 메뉴에서 1~4). 끌어서 순서 변경·다른 칸으로 옮기기, 폴더를 탭 줄에 놓으면 새 탭, 가운데 클릭으로 닫기
- **경로 표시줄**: 드라이브·폴더 이름 클릭 → 이동, `›` → 하위 폴더 목록, 빈 곳 클릭 → 주소 직접 입력
- **보기 방식**(보기 메뉴·탭 우클릭 → 보기): 아주 큰 아이콘·큰 아이콘·보통 아이콘·작은 아이콘·목록·자세히·타일·내용 (Ctrl+Shift+1~8, 탐색기와 같음)
- **자체 검색**: 검색창에서 Enter → 현재 폴더(내 PC 면 모든 드라이브)의 하위 폴더까지 이름으로 찾아 탭 안에 결과 목록을 보여 줌 (윈도우 탐색기를 열지 않음). `*`·`?` 와일드카드, 여러 낱말(모두 포함) 지원. Backspace·Esc 로 결과 닫기
- **탭 우클릭 → 모든 폴더에 적용**: 그 탭의 보기 방식·아이콘 크기·정렬·열·열 너비·그룹을 모든 칸·모든 탭·앞으로 여는 모든 일반 폴더에 적용 (내 PC·검색 결과 등은 제외). 해제는 보기 → 모든 폴더 보기 설정 해제
- **테마**: 보기 → 테마 (윈도우 설정 따름 / 밝게 / 어둡게). 탐색기 보기·트리·제목 줄까지 다크 모드 (윈도우 10 1809 이상). 미리 보기 창은 윈도우 10 자체가 밝은색만 지원
- **우클릭 메뉴 등록**: 시작할 때 폴더·드라이브·폴더 빈 곳 우클릭에 `몽탐색기로 열기` 를 자동 등록(HKCU, 관리자 권한 불필요). 실행 중인 exe 경로로 항상 갱신되며, 도움말 메뉴에서 끄면 등록 해제 (`test` 폴더·시험 실행은 등록 안 함)
- 미리 보기 창(Alt+P)·세부 정보 창(Alt+Shift+P)은 모든 칸 공통

## 단축키
Ctrl+T 새 탭 · Ctrl+W 탭 닫기 · Ctrl+Tab 다음 탭 · Alt+1~4 칸 고르기 · Alt+←/→/↑ 뒤로/앞으로/위로 · Backspace 뒤로 · F5 새로 고침 · Ctrl+L/Alt+D/F4 주소 · Ctrl+E/Ctrl+F/F3 검색 · Ctrl+Shift+1~8 보기 방식 · Ctrl+Enter·가운데 클릭 폴더를 새 탭으로 · Ctrl+Shift+N 새 폴더(바로 이름 바꾸기) · Ctrl+V 붙여넣기 후 붙여넣은 항목 선택 · 마우스 뒤로/앞으로 버튼. 그 밖의 키(F2, Delete, Ctrl+C/X/Z/A ...)는 탐색기 보기가 그대로 처리

## 개발
- 빌드: `build.bat` → `bin\몽탐색기.exe` + `release\몽탐색기.exe`(커밋 대상, 자동 업데이트가 받는 파일). 옛 이름 설치본이 받아가도록 `release\NewExplorer.exe` 도 같이 만든다(모든 PC 가 업데이트되면 지워도 됨). 앱 이름은 `app.name` 에서 읽는다(배치 파일은 ASCII 만 사용). 앱이 켜져 있어 bin 을 못 덮으면 `build.bat test` → `test\`
- **버전**: 저장소 루트 `VERSION` 하나 (build.bat 이 `src\Version.cs` 생성). 고쳐서 커밋할 때마다 0.01 올리고 `release\몽탐색기.exe`·`release\NewExplorer.exe` 도 함께 커밋 → 푸시하면 다른 PC 가 업데이트 받음
- 시험: `몽탐색기.exe --pos 30,-1060,1860,1000 --noactivate --selftest <로그>` — 2번 모니터에 포커스 없이 띄우고 주요 동작(칸 배치·이동·트리·탭 옮기기·모든 폴더에 적용·보기 방식 8가지·칸 바꾸기·다크 모드·새 폴더·붙여넣은 항목 선택)을 차례로 실행해 결과와 화면(png)을 로그 폴더에 남김 (설정 저장 안 함)
- 폴더별 보기 기억은 ExplorerBrowser 속성 모음 이름 `NewExplorer` (윈도우 탐색기 설정과 별개)
- C# 5 문법만 사용 (.NET Framework 4 기본 컴파일러)
